A function $f(x)$ is piecewise continuous on $[a, b]$, if it's continuous on all but a finite amount of points $a = x_0 < x_1 < ... < x_n = b$, and in every interval $(x_{k - 1}, x_k)$ the limits $f(x_{k - 1} + 0)$ and $f(x_k - 0)$ exist and are finite.
A function is piecewise continuous on an interval $I$ (finite or infinite) if it's piecewise continuous on any closed interval within $I$.
## Properties
- If $f, g$ are piecewise continuous, $f + g$, $\lambda f$, $fg$ are piecewise continuous
- Every piecewise continuous function on a closed range is bounded in it
- Every piecewise continuous function on a closed range is integrable in it
