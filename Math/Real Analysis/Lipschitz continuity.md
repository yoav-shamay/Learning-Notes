A function $f(x)$ has Lipschitz continuity if there's a constant $L$ satisfying $|f(x_1) - f(x_2)| \leq L|x_1 - x_2|$ for every $x_1, x_2$ in the domain.
## Properties
- Any function with a bounded derivative $f'(x) \leq L$ in an interval is Lipschitz continuous on it, with the constant $L$.
## Multivariate Functions
For a multivariate function, a function has Lipschitz continuity on $x$ if there's $L$ satisfying $|f(x_1, y) - f(x_2, y)| \leq L|x_1 - x_2|$ for every $x_1, x_2, y$ in the domain.
It can be defined equivalently for $y$, or for more variables.
