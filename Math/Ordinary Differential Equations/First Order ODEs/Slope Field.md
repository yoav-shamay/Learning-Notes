A geometric visualization for the solutions of a first order ODE.
Given an equation $y' = f(x, y)$, this means that the slope at each point $(x, y)$ if it's on the solution is $f(x, y)$.
So by passing a line of slope $f(x, y)$ at each point $(x, y)$, the solution will be tangent to all lines of the points it passes through.
By drawing a bunch of those lines we can draw a visualization for the ODE and create an approximated solution graph.
