## Bernoulli Equations
Equation of the form $y' + a(x)y = b(x)y^m$ for a constant $m$.
If $m = 1$ (or zero) this is a [[Linear First Order ODEs]] which is easily solvable.
Otherwise, we substitute $z = y^{1-m}$ and get $\frac{1}{1 - m} z' + a(x)z = b(x)$ 
This is a [[Linear First Order ODEs]].
## Homogenous Equation
Equation of the form $y' = f(y/x)$.
We substitute $z = y/x$ and get $z'x + z = f(z)$ (or $(f(z)-z)dx-xdz=0$) which can be solved using [[Substitution of Variables]].
