A field extension $K / F$ is called algebraic if every $x \in K$ is [[Algebraic Elements of Field|algebraic]] over $F$.
Otherwise, the extension is called Transcendent.
## Properties
- For a transcendent extension $K / F$, all algebraic elements of $K$ over $F$ is a sub-field of $K$ (a middle field between $F$ and $K$)
- An extension $K / F$ is finite iff it's an algebraic extension generated from adding a finite number of elements to $F$.
- $\mathbb{R}/\mathbb{Q}$ is a transcendent extension
