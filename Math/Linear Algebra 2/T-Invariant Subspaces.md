## Invariant subspaces
- $W \subseteq V$ linear subspace is called a $T$ invariant subspace if $T(W) \subseteq W$
- Examples: Eigenspace, subspace of eigenspace, $\ker{T}$, $\text{Im}\ T$.
- $Orb_T(v) = Sp\{v, T(v), T^2(v), ...\}$ - the T-orbital subspace generated by $v$.
- $Orb_T(v)$ is a T-invariant subspace and is a subspace of every T-invariant subspace that contains $v$.
- for invertible $T$ and finitely created $U$, if $U$ is T-preserved then $U$ is $T^{-1}$ preserved.
- You can reduce the domain of a T-preserved subspace to this subspace, denoted as $T|_W(v)$
if $U$ is $T_1, T_2$ invariant:
- $U$ is $T_1+T_2$ invariant and $(T_1 + T_2)|_U = T_1|_U + T_2|_U$
- $U$ is $T_1T_2$ invariant and $(T_1T_2)|_U = T_1|_U T_2|_U$
- $U$ is $aT_1$ invariant and $(aT_1)|_U = a(T_1|_U)$
- If U is $T$ invariant and $W$ is $T|_U$ invariant then $W$ is $T$ invariant and $(T|_U)|_W = T|_W$
- if $TS = ST$ and $W$ the eigenspace of $\lambda$ on $T$ then $W$ is $S$-invariant.
- if $S$ is diagonalizable and $K \subseteq V$ is S-invariant then $S|_K$ is diagonalizable
- If $W$ is $T$-invariant then $W^{\perp}$ is $T^*$-invariant.
### Representing matrix of transformation using direct sum including a T-invariant subspace
Denote the projection on $V_1$ where $V = V_1 \oplus V_2$ as $T_{V_1, V_2}$
Let $T$ be a linear transformation on $V$
$V = V_1 \oplus V_2$
$V_1$ is a T-preserved space
$v = (v_1,...,v_k)$ basis for $v_1$
$w = (w_1,...,w_{n-k})$ basis for $V_2$,
$B = (v_1,...,v_k,w_1,...,w_{n-k})$ basis for $V$,
$M = [T]_B$.
Then:
$$
M = \begin{pmatrix}
A\ C \\
0\ B
\end{pmatrix}
$$
and:
$$
\begin{matrix}
A = [T|_{V_1}]_v \\
B = [T_{V_2,V_1}T|_{V_2}]_w \\
P_M(x) = P_A(x)P_B(x)
\end{matrix}
$$
and if $V_2$ is also T-preserved:
$$
\begin{matrix}
C = 0 \\
B = [T|_{V_2}]_w
\end{matrix}
$$
