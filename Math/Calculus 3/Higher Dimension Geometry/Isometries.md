A function $\varphi : R^k \to R^l$ is an isometry iff $|\varphi(x) - \varphi(y)| = |x - y|$.
## Properties
- Composition of isometries is an isometry.
- $\varphi$ is an isometry iff $\varphi(x) = xP + b$ for an Orthogonal matrix $P$ and a vector $b$.
- Every isometry is affine.
- $\varphi$ is an isometry iff for every $x, y, z \in R^k$, $(\varphi(x) - \varphi(y))(\varphi(z) - \varphi(y)) = (x - y)(z - y)$
- $\varphi(B(a ; r)) = B(\varphi(a) ; r)$
