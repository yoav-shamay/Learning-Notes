A set $A \subseteq R^k$ is an affine subspace iff it's of the form $L + b = \{x + b | x \in L\}$ for $L \subseteq R^k$ a linear subspace and a vector $b \in R^k$.
If $\dim L = b$, we also say $\dim S = b$.
## Properties
- The subspace $L$ is unique. In other words, if $L_1 + b_1 = L_2 + b_2$ then $L_1 = L_2$
- An affine subspace is also a linear subspace iff $0$ is in it.
- Equivalently, for an affine subspace, we get $L$ by subtracting any vector in it.
- $A$ is an affine subspace of $R^k$ iff for each $x, y \in A$ and $\alpha, \beta \in R$ such that $\alpha + \beta = 1$, then $\alpha x + \beta y \in A$ (note that it differentiates from convex requirement as it isn't only for $\alpha, \beta \geq 0$)
- Every affine subspace is convex
