## Partial Function
A partial function from $R^k$ is a function that its domain is a subset of $R^k$.
It's said to be defined at a point or set $A$ if $A$ is a subset of its domain.
## Reduction of function
For a partial function $f$ to $B$, the reduction of $f$ of a set $A$ is $f$ but its domain is reduced to $A$, and denoted $f|_A: A \to B$.
## Components of a function
Given $f$ a partial function to $R^l$, its $i$th component $[f]_i$ for $1 \leq i \leq l$ is the function that outputs the $i$th component of $f(x)$ (with an image in $R$).
## Slice of a function
Given $f$ a partial function from $R^k$ to $R$, and $a, u \in R^k$, the slice of $f$ in point $a$ in the direction of $u$ is $f|_{a, u} (t) = f(a + tu)$
### Properties
- $f|_{a, \lambda u}(t) = f|_{a, u}(\lambda t)$
