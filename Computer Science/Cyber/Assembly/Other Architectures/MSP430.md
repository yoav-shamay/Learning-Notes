Used in the microcorruption site
16-bit.
Registers:
- `r0/pc` (program counter)
- `r1/sp` (stack pointer)
- `r2/sr` - status register - contains various flags that are set in arithmetic operations.
- `cg` (?)
- `r04`,`r05`,`r06`,`r07`,`r08`,`r09`,`r10`,`r11`,`r12`,`r13`,`r14`,`r15` - general purpose
Similar to normal `x86`. Can understand.
Can decompile in IDA Pro or Ghidra,
The stack, `call` and `ret` work normally.
Instruction reference: https://www.ti.com/sc/docs/products/micro/msp430/userguid/ag_b.pdf
## `sr` register
bits (from LSB to MSB) are numbered 0..15
Bit 0 - carry flag - 1 if carry, 0 if not, inverted in `sub`
Bit 1 - zero flag - on if result is zero
Bit 2 - neg flag - on if result is negative, bit 7 is on on byte operations or bit 15 on word.
Bit 4 - `cpuoff` bit - if set on, CPU is turned off immediately.
