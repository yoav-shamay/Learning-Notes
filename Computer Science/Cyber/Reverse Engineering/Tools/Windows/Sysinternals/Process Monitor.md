Part of sysinternals
A windows tool that allows to see system operations of each process, like file read or registry reading.
Can filter.
Like `strace` for windows.
## Tips
- stop recording after finishing to capture the events you want (Ctrl + E)
## Quick filtering
- When right clicking an entry has specific include / exclude options about it (type / value)
- The top menu, on the right, allows to filter to file operations / registry operations / process creation operations
## Stack View
- Allows to see process stack on call
- Specifically, the lowest library one is the exact library call performed
- Can be useful when in executables.
