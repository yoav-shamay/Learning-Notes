## Mathematical Definition
Defined over a field.
In ECC, the field is usually $F_P$.
An Elliptic Curve is the set of solutions $(x,  y)$ to a Weierstrass Equation $Y^2 = X^3 + aX + b$, with the point at infinity ($O$).
$a$ and $b$ must satisfy $4a^3 + 27b^2 \neq 0$.
Addition is defined as following:
- Intuitively, draw a line between the 2 points, find the third intersection with the curve, and reflect it from the x-axis (multiply y by -1). If there's no third intersection, the result is the point at infinity ($O$). Note that this geometric visualization fails over a finite field, as it's no longer a curve. 
Mathematically:
- $(x, y) + O = O + (x, y) = (x, y)$ ($O$ is the identity element).
- $(x, y) + (x, -y) = O$ ($-(x, y) = (x, -y)$).
Otherwise, for $P = (x_1, y_1)$ and $Q = (x_2, y_2)$:
- If $P \neq Q$, $\lambda = (y_2 - y_1) / (x_2 - x_1)$
- If $P = Q$, $\lambda = (3x_1^2 + a)/2y_1$
- $P + Q = (\lambda^2 - x_1 - x_2, \lambda(x_1 - x_3) - y_1)$
Scalar multiplication can be computed like standard exponentiation.
## Basic info about the Elliptic Curve group
- The group is abelian.
- Multiplication - repeated addition - easy (fast)
- Discrete logarithm (inverse multiplication / division) - hard (no known polynomial algorithm)
- Identity element - point at infinity, $O$.
## Generators
When using an Elliptic curve, you usually choose an element $G$ called a "generator" of large prime order.
Not actually a real generator of the entire group as it isn't cyclic.
Then you use the cyclic subgroup generated by $G$.
This can be created using sagemath by using `E.gen()` or `E.gens()` for a list in case of multiple.
## Order
Hasse's theorem:
For an elliptic curve on $GF(p)$ with order $N$: $|N - (p + 1)| \leq 2\sqrt{p}$
$p$ doesn't have to be prime.
## Trace of Frobenius
The trace of Frobenius of an elliptic curve $E$ with order $n$ over $\mathbb{Z}_p$ is $t = p + 1 - n$.
According to Hasse's theorem, $t \leq 2\sqrt{p}$.
