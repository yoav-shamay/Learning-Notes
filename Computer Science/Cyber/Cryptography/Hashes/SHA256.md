## Padding
The block size is 512 bits (64 bytes), and the length is always divisible by it.
Given a message as a sequence of bits:
Add a 1 bit (in bytes note that its big endian so it's `\x80`).
Pad with zeros until the `bit length + 64` is divisible by 512 (`byte length + 8` is divisible by 64).
Alternatively, `original message bit length + 1 + 64`, to account for 1 bit.
Then the **bit** length is added as a 64 bit big-endian integer.
## Algorithm
### Initialization
Initialize hash values: (first 32 bits of the fractional parts of the square roots of the first 8 primes 2..19)
```
h0 = 0x6a09e667
h1 = 0xbb67ae85
h2 = 0x3c6ef372
h3 = 0xa54ff53a
h4 = 0x510e527f
h5 = 0x9b05688c
h6 = 0x1f83d9ab
h7 = 0x5be0cd19
```
Initialize array of 64 round constants (first 32 bits of the fractional parts of the cube roots of the first 64 primes 2..311)
```
k[0..63] = [0x428a2f98, 0x71374491, 0xb5c0fbcf, 0xe9b5dba5, 0x3956c25b,0x59f111f1, 0x923f82a4, 0xab1c5ed5,0xd807aa98, 0x12835b01, 0x243185be, 0x550c7dc3, 0x72be5d74, 0x80deb1fe, 0x9bdc06a7, 0xc19bf174,0xe49b69c1, 0xefbe4786, 0x0fc19dc6, 0x240ca1cc, 0x2de92c6f, 0x4a7484aa, 0x5cb0a9dc, 0x76f988da,0x983e5152, 0xa831c66d, 0xb00327c8, 0xbf597fc7, 0xc6e00bf3, 0xd5a79147, 0x06ca6351, 0x14292967,0x27b70a85, 0x2e1b2138, 0x4d2c6dfc, 0x53380d13, 0x650a7354, 0x766a0abb, 0x81c2c92e, 0x92722c85,0xa2bfe8a1, 0xa81a664b, 0xc24b8b70, 0xc76c51a3, 0xd192e819, 0xd6990624, 0xf40e3585, 0x106aa070,0x19a4c116, 0x1e376c08, 0x2748774c, 0x34b0bcb5, 0x391c0cb3, 0x4ed8aa4a, 0x5b9cca4f, 0x682e6ff3,0x748f82ee, 0x78a5636f, 0x84c87814, 0x8cc70208, 0x90befffa, 0xa4506ceb, 0xbef9a3f7, 0xc67178f2]
```
### Processing chunks
For each 512 bit (64 byte) chunk of the padded input:
#### `w` creation
Create an array `w` of length 64 of 32-bit numbers.
Initial value doesn't matter, most implementation zero them.
Copy the chunk to `w[0..15]` (`w[0]` is the most significant)
Then initialize  all `w`:
```
for i from 16 to 63:
	s0 = (w[i - 15] rightrotate 7) ^ (w[i - 15] rightrotate 18) ^ (w[i - 15] >> 3)
	s1 = (w[i - 2] rightrotate 17) ^ (w[i - 2] rightrotate 19) ^ (w[i - 2] >> 10)
	w[i] = w[i - 16] + s0 + w[i - 7] + s1
```
Where `rightrotate` is right cyclic shift.
#### `w` compression
Then compress `w` to 8 values:
##### Initialization
Initialize them to the hash values:
```
a = h0
b = h1
c = h2
...
h = h7
```
##### Processing
```
for i from 0 to 63:
	S1 = (e rightrotate 6) ^ (e rightrotate 11) ^ (e rightrotate 25)
	ch = (e & f) ^ ((~e) & g)
	temp1 = h + S1 + ch + k[i] + w[i]
	S0 = (a rightrotate 2) ^ (a rightrotate 13) ^ (a rightrotate 22)
	maj = (a & b) ^ (a & c) ^ (b & c)
	temp2 = S0 + maj
	h = g
	g = f
	f = e
	e = d + temp1
	d = c
	c = b
	b = a
	a = temp1 + temp2
```
In the end, add the 8 values to the matching hash values:
```
h0 += a
h1 += b
h2 += c
...
h7 += h
```
### Generating digest
The digest will be generated by concatenation of the 8 hash values (`h0` is the most significant):
`digest = h0 append h1 append h2 append ... append h7`
