## TCP Server
- http://pinggy.io - free tcp and http forwarding from my machine, very easy to setup (just open the home page and it explains how)
## HTTP Server
- ngrok: run `ngrok http port` to forward port from my machine, also has permanent url.
- tunnelmole: run `tmole port`. Doesn't have the confirmation part of `ngrok` so actually works on headless browsers.
## Azure VM
Students can create a free azure linux VM which has a public IP address.
Can connect using `ssh`, and transfer files using `scp`.
