A SAT solver library.
Can solve relatively simple constrained equations.
Can be useful for crypto / rev, though won't work for real ciphers.
Usage:
```python
from z3 import *
s = Solver()
# defining variables
var = BitVec('name', bit_count)
var2 = Int('name')
var3 = Real('name')
var4 = Bool('name')
# adding constraints
s.add(var >= 5, var <= 8)
s.add(var + var2 == 7)
s.add(Or(var == 2, var == 3))
s.add(Or([var == x for x in [1, 2, 3, 4, 5]]))
# solving
if s.check() == sat:
	sol = s.model()
	print(sol[var].as_long()) # number
	print(sol[var2].as_long()) # number
	print(sol[var3].numerator_as_long(),'/',sol[var3].denominator_as_long())
	print(is_true(sol[var4])) # True / False
```
Statuses:
- `sat` - found a solution
- `unsat` - found a contradiction
- `unknown` - couldn't solve
